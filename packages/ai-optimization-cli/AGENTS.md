# AI Optimization CLI

Use this package when agent workflows need DataForSEO AI Optimization data.

- Prefer `llmResponse dataset models` before a paid live LLM response call.
- Use `llmMention dataset search` for raw mention rows.
- Use `llmMention dataset aggregatedMetrics`, `topPages`, `topDomains`, or `crossAggregatedMetrics` for aggregate reporting.
- Credentials come from `DATAFORSEO_LOGIN` and `DATAFORSEO_PASSWORD`, usually through the active product-growth profile.
